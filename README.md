# C++ 工作台

简洁的浏览器 C++ 编辑器，打开后即可写代码。

## 功能

- C++ 语法高亮、行号、Tab 缩进与自动缩进
- 标准输入、编译信息、标准输出与错误输出
- 通过 Wandbox 调用真实 GCC 编译器，使用 C++17
- 浏览器内的基础 C++ 调试：断点、暂停、单步执行和变量查看
- 草稿自动保存在当前浏览器，可下载 `main.cpp`
- 支持手机与电脑

## 发布为网站

打开本仓库的 **Settings → Pages**：

1. **Source** 选择 **Deploy from a branch**。
2. **Branch** 选择 **main**，目录选择 **/ (root)**。
3. 点击 **Save**，等待 GitHub 完成部署。

Pages 设置页会显示实际发布网址：
https://stuffdivine795-cmyk.github.io/cpp-lab/

## 编译与数据

网站是静态网页；GitHub Pages 本身不执行 C++。点击运行时，源代码与标准输入会发送到 Wandbox 在线编译服务。运行需要联网，服务不可用时会显示错误，编译请求超过 30 秒会取消等待。

“停止”取消当前浏览器请求，并不保证停止远端进程。自动保存仅存在于当前浏览器，不会将练习代码上传至此 GitHub 仓库。清理浏览器数据会删除草稿，建议下载重要代码。

## 如何调试

1. 如有 `cin`，先在标准输入中填好数据。
2. 点击左侧行号设置断点，红点表示该行有断点。
3. 点击顶部“调试”。程序会先暂停在可执行的位置。
4. “下一步”执行到下一行，“继续”执行到下一个断点，“暂停”暂停正在执行的调试，“结束”停止调试。
5. 黄色高亮表示接下来要执行的位置；右侧变量表显示当前变量的类型和值。函数调用也会逐步进入函数。
6. 调试过程中源码和标准输入固定；结束后可编辑并重新开始。

### 范围与限制

调试采用 [JSCPP](https://github.com/felixhao28/JSCPP) 的浏览器 C++ 解释器，支持基础变量、数组、条件、循环、函数和输入输出。它是真正暂停解释执行的调试器，并非运行后回放。

调试器不等同于 GCC/GDB，不保证完整 C++17、复杂类、`vector`、`std::string`、模板、复杂标准库或多文件程序的兼容性。不支持的代码会显示调试错误；常规“运行”仍调用 GCC。没有初始化的声明等不产生解释器执行位置的行，可能不会触发断点。

调试代码在独立 Web Worker 中本地解释，不会发送至编译服务。“结束”直接终止 Worker。每次调试限制为 200,000 次解释操作和 100,000 字符输出；一次执行动作等待超过 15 秒会停止 Worker，避免死循环持续运行。

### 验证与第三方来源

`node tests/debugger.test.js` 可验证输入、断点暂停、逐行执行、变量变化、循环断点、函数作用域、单行循环、死循环上限及语法错误。调试控制消息与前端状态还进行了执行检查。

第三方浏览器引擎保存在 `vendor/JSCPP.es5.min.js`，来自 JSCPP 的 `gh-pages` 提交 `76e3534f04abf9c2547aa73ddca275e8935bed38`，原文件 blob 为 `ddb004d4c15696bf98660e5a416e2781ba947666`。MIT 许可保存在 `vendor/JSCPP.LICENSE`。
